# چک‌لیست آزمون رابط و تم‌ها (آپارتمانت)

> هدف: هر تغییر UI جدید (به‌ویژه تنظیمات، کشوها، تیک‌ها و آموزش) قبل از انتشار با این مدل بررسی شود.  
> آخرین به‌روزرسانی: ۱۴۰۴/۰۸/۰۶ (۲۰۲۶-۱۰-۲۸) — هم‌زمان با کشوی «ساختمان‌ها» در ۱.۸.۰.

## ۱) تم‌ها و پالت‌ها (همه باید خوانا باشند)

در «تنظیمات ← تنظیمات ظاهری» هر ترکیب زیر را یک‌بار باز کنید و کنترل جدید را ببینید:

| حالت | پالت‌ها |
|------|---------|
| روشن | آسمان (پیش‌فرض)، کاغذ، نعنایی، اسطوخودوس، خاکستری‌خنک |
| تاریک | سرمه‌ای، زغالی، AMOLED، گرم |

برای هر تم:

- [ ] متن و آیکن روی پس‌زمینهٔ کارت خواناست (کنتراست کافی).
- [ ] سوییچ‌ها و دکمه‌های اصلی رنگ برند همان تم را دارند.
- [ ] هیچ رنگ ثابت روشن/تیره‌ای که فقط در یک تم درست باشد دیده نمی‌شود.

## ۲) تیک / حالت انتخاب‌شده

هر جایی که گزینهٔ فعال با تیک (`year-row__box` + `IconCheck`) یا مشابه مشخص می‌شود:

- [ ] روی گزینهٔ فعال، کادر تیک پرِ رنگی است و خودِ تیک سفید و واضح است.
- [ ] روی گزینه‌های غیرفعال، کادر خالی/حاشیه‌دار است و تیک نیست.
- [ ] در **همهٔ ۹ تم بالا** تیک ناپدید یا هم‌رنگ زمینه نمی‌شود.
- [ ] آزمون خودکار مرتبط: `tests/checkmarkVisibility176.test.ts` (و در صورت نیاز `selectedStateContrast`).

## ۳) برابری کشو با کنترل‌های مشابه

انتخابگرهای جدید باید مثل «سال‌های فعال» / `OptionPicker` / `SelectField` باشند:

- [ ] سربرگ کشویی: برچسب + مقدار فعلی + فلش.
- [ ] با باز شدن، فهرست با ردیف‌های `year-row` و تیک گزینهٔ فعال.
- [ ] با انتخاب یک گزینه، کشو بسته می‌شود و مقدار سربرگ عوض می‌شود.
- [ ] **نه** تراشه/`seg` جدا برای حالتی که بقیهٔ برنامه کشو دارد (مگر الگوی صریح دیگری در طرح باشد).

نمونهٔ فعلی: «ساختمان فعال» در تنظیمات ← ساختمان‌ها (وقتی سوییچ چند ساختمان روشن است).

## ۴) چند ساختمان (رفتار)

- [ ] سوییچ کنار عنوان آکاردئون «ساختمان‌ها» است؛ توضیح کوتاه زیر عنوان مانده است (حذف نشود مگر مالک بخواهد).
- [ ] سوییچ خاموش → کشو و افزودن ساختمان دیده نمی‌شود؛ کار مثل یک ساختمان.
- [ ] سوییچ روشن → کشوی ساختمان فعال + افزودن + تغییر نام / بایگانی.
- [ ] تعویض ساختمان، واحدها / صندوق / دورهٔ مدیریت همان ساختمان را نشان می‌دهد.
- [ ] ساختمان پیش‌فرض بایگانی‌شدنی نیست.

آزمون خودکار دامنه: `tests/offlineUi180.test.ts`, `tests/sqlite180.test.ts`.

## ۵) آموزش / راهنما

- [ ] موضوع آموزش برای قابلیت جدید وجود دارد (جست‌وجو با کلیدواژه‌های کاربر مثل «چند ساختمان»، «ساختمان‌ها»، «سوییچ»).
- [ ] لینک «راهنمای این بخش» روی آکاردئون تنظیمات به همان موضوع می‌رود (`ACCORDION_TOPIC`).
- [ ] متن فقط «طرز استفاده» است؛ بدون فرمول یا مثال عددی محاسبه‌ای (`tests/help177.test.ts`).
- [ ] نام دکمه‌ها و عنوان بخش‌ها با UI یکی است (مثلاً «ساختمان‌ها» نه فقط «ساختمان» اگر عنوان UI عوض شده).

## ۶) قبل از کامیت / همگام‌سازی ویندوز

- [ ] `npm test` (یا حداقل help + theme + تست‌های بخش مربوط) سبز است.
- [ ] اگر رنگ هگز در `global.css` عوض شد: `npm run theme:generate` و دوباره تست تم.
- [ ] کامیت روی `main` با پیام واضح؛ **بدون** ساختن release مگر مالک بخواهد.
- [ ] درخت ویندوز `F:\Apartmanet\building-charge` با همان کامیت همگام شود.
